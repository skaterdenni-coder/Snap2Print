# Snap2XR 🚀

**Snap2XR** transforms 2D photos into high-quality 3D models using AI and makes them instantly accessible for Augmented Reality (AR).

🌐 **Live Web Version:** [https://skaterdenni-coder.github.io/Snap2Print/](https://skaterdenni-coder.github.io/Snap2Print/)

[Deutschsprachige Version unten](#de-snap2xr-2d-zu-3d-anwendung)

---

## 🌟 Key Features

- **Web Deployment**: Directly accessible via GitHub Pages without any local installation.
- **AI 3D Generation**: Powered by the Tripo AI Engine to create detailed 3D assets.
- **Dual Workflow**:
    - **Single-View Mode**: Generate models from one photo for quick results.
    - **Multiview Mode**: Use 4 perspectives (Front, Left, Right, Back) for maximum precision.
- **AR Viewer Integration**: Instant AR preview via a custom web viewer.
- **Cloud Hosting**: Seamlessly uploads models to storage services (like Litterbox) for instant sharing.
- **Smart History**: Local storage for all your models, including thumbnails and automatic object naming.
- **Modern UI**: Adaptive design with Light and Dark mode.
- **Extreme Quality**: Users can unlock a quality selector to generate **8K (Extreme)** textures for ultra-high fidelity models.

## 🛠 Tech Stack
- React Native / Expo (TypeScript)
- GitHub Pages Deployment
- Tripo AI V3 OpenAPI

## 🚀 Usage & Local Setup

### Live Web App
Access the deployed web version directly here:  
👉 [https://skaterdenni-coder.github.io/Snap2Print/](https://skaterdenni-coder.github.io/Snap2Print/)

*(Note: Don't forget to enter your Tripo API key in the app settings)*

### Local Setup
1. `bun install` or `npm install`
2. `npx expo start` (or `npx expo start --web` for local web view)
3. Enter your Tripo API Key in the settings.

# DE: Snap2XR 2D zu 3D Anwendung

**Snap2XR** verwandelt 2D-Fotos mithilfe von KI in hochwertige 3D-Modelle, die sofort in Augmented Reality (AR) erlebt werden können.

🌐 **Live Web-Version:** [https://skaterdenni-coder.github.io/Snap2Print/](https://skaterdenni-coder.github.io/Snap2Print/)

## ✨ Hauptmerkmale

- **Web-Deployment**: Direkt über GitHub Pages erreichbar – ohne lokale Installation sofort nutzbar.
- **KI-3D-Generierung**: Nutzt die Tripo AI Engine für detaillierte 3D-Objekte.
- **Flexibler Workflow**:
    - **Single-View**: Erstellung aus nur einem Bild für schnelle Entwürfe.
    - **Multiview**: Nutzung von 4 Perspektiven (Vorne, Links, Rechts, Hinten) für höchste Präzision.
- **AR-Integration**: Direkte AR-Vorschau über einen spezialisierten Web-Viewer.
- **Cloud-Hosting**: Automatischer Upload zu Diensten (wie Litterbox) für schnelles Teilen.
- **Lokale Historie**: Speichert alle Modelle inkl. Vorschaubildern und automatischer Benennung.
- **Adaptives Design**: Modernes UI mit Hell- und Dunkelmodus.
- **Extreme Qualität**: Über einen Schalter lässt sich die **8K (Extreme)** Textur-Generierung für maximale Detailtiefe aktivieren.
